# 共通環境メモ（home-manager管理）

この環境には Rust 製の高速な CLI が揃っている。標準コマンドの代わりに
こちらを優先して使うこと（大きいリポジトリでは体感で桁が違う）。

## 検索・ファイル操作

| 用途 | 使うもの | 代替される標準コマンド | 備考 |
| --- | --- | --- | --- |
| 全文検索 | `rg` (ripgrep) | `grep -r` | gitignore を自動で尊重する。`grep` は `rg` にエイリアス済み |
| ファイル検索 | `fd` | `find` | `fd <pat>` だけで再帰検索。`-H` で隠しファイル、`-e md` で拡張子指定 |
| 一覧 | `eza` | `ls` | `ls`/`lsa`/`tree` がエイリアス済み |
| 表示 | `bat` | `cat` | パイプ時は自動でプレーン出力。素の内容が欲しいなら `bat -p` |
| 置換 | `sd 'from' 'to' <file>` | `sed -i` | 正規表現がPerl風でエスケープが少ない。BSD/GNU sed の差異を踏まない |
| ファジー選択 | `sk` (skim) | `fzf` | シェル関数 `fuzzy_search` 経由でも呼べる |
| 展開・圧縮 | `ouch d <file>` / `ouch c <out> <in>` | `tar`/`unzip`/`zstd` | 形式を自動判別する |

## 計測・調査

| 用途 | 使うもの | 代替される標準コマンド |
| --- | --- | --- |
| ディスク使用量 | `dust` | `du -sh` |
| プロセス一覧 | `procs` | `ps aux` |
| リソース監視 | `btm` (bottom) | `top` / `htop` |
| 定期実行の監視 | `hwatch <cmd>` | `watch` |
| ベンチマーク | `hyperfine '<cmd>'` | `time` の手動繰り返し |
| コード行数 | `tokei` | `wc -l` + `find` |

`hyperfine` は「速くなったか」を主張する前に必ず通すこと。体感や単発 `time`
での比較は根拠にしない。

## その他

- `jq` … JSON 処理（`yq` は入れていないので YAML は Python 等で扱う）
- `hunk` … 変更セットをターミナルで diff 表示する。agent の変更レビュー向け
- `yazi` … ターミナルファイルマネージャ（対話用途。agent からは使わない）
- `hx` (helix) … エディタ。agent は直接ファイル編集ツールを使うこと
- `mise` / `uv` … ランタイムと Python パッケージ管理。`pip` は `uv pip` にエイリアス済み

## 注意

- ここに無いツールを使う前に、上の表に代替が無いか確認する。
- 対話専用のツール（`yazi`, `hx`）を非対話シェルから起動しない。
